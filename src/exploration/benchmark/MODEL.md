# 固定扫描与按路访问的两阶段模型

本稿对应已实现的 `two_stage.py`，限定第三问全向源。用户已明确授权建模并多组测试。最新结果见 [总报告](RESULTS.md)。本模型取代本任务此前误用的纯逐格试清基线。

后续官方核验：已单独完成一次问题3真实演练，11/11全清、59.46分钟；117动作本地官方反馈重放一致，独立计费累计最大差异约1.24微秒。**未获得官方隐藏源坐标、接收半径和误差场，故未完成同场景自建环境独立对比**。见 [官方演练与重放报告](runs/official_practice_77UA/RESULTS.md)。下文140次批量运行仍全部属于自建环境，勿与这一次官方演练混记。

## 1. 两个阶段与评价目标

第一阶段用预先确定的测点和巡查次序，集中积累多频道、多方向信息；不要求全部目标都进入20米清除范围。第二阶段根据当前估计中心规划访问顺序，前往目标时补测或在小范围内尝试清除。每次获得真实反馈后更新位置区域。

所有源清除后才算成功。单局费用为

\[
T=\frac{\ell}{5}+5n_{\rm measure}+n_{\rm switch}+5N+3n_{\rm fail}.
\]

长度 ell 单位米，时间单位秒。主指标为逐局 T/N 后对案例等权平均；整局分钟、阶段时间与失败次数辅助解释。阶段一和阶段二的总成本共同决定方案好坏。

## 2. 固定扫描怎样构造

以原点加半径1200米正六边形的七点为基础，所有候选均保留这七点，继承“任何全向源至少能被一个测点接收”的覆盖关系。比较的额外点为：

- 13点：再加半径1600米、角度30+60k度的六点。
- 19点：再加半径1700米、角度15+30k度的十二点。

巡查从原点开始，用最近邻加2-opt事先排定点位访问次序。它只依赖预定义点集，不读源真值，也不随案例改变。没有证明候选点集或巡查次序全局最优。七点完整路程7200米，移动24分钟。

每个点按频道号扫描。**发现一个源之后仍然继续扫描该频道**，除非它的保守包围圆半径已不超过扫描停止阈值 rho。已经证明不存在的频道跳过。比较 rho=60米与30米；它是“停止继续收集这个频道信息”的阈值，不是所有源第一阶段结束时都必须满足的保证。

设该频道可能位置为 P_j。每次正测向用带误差扇形、最大1500米接收距离与源域相交；无信号在Q3排除测点1000米必接收圆。使用已有保守几何实现，扇形半角1.00500001度，容纳题面±1度及两位小数舍入。阴性排除采用保守保留小格，不用离散抽样宣布不存在。

七点不足以保证全部目标完成交会定位。实验必须报告阶段一仍然宽大的区域数量；代码将其留到第二阶段补测，不伪造第一阶段定位成功。第一阶段只扫描，不提前逐个绕路清除；near信息也保留到访问阶段使用。

## 3. 访问顺序怎样规划

对每个未清除目标，计算保守区域的包围圆圆心 c_j，作为本轮访问位置的代理。从实际当前位置 x 出发，不要求返回原点，求

\[
\min_\pi\left[\|x-c_{\pi_1}\|+\sum_{i=2}^{n}\|c_{\pi_i}-c_{\pi_{i-1}}\|\right].
\]

通过子集动态规划求给定中心坐标的最优开放路径。使用已有微米整数距离向下取整，误差最多 n 微米；原点只用于整局起步，第二阶段从最后实际扫描点开始。每清除一个目标，从实际清除位置对剩余目标重算访问顺序，继续完成排在首位的目标。

**精确性只针对当前估计中心的访问顺序。** 中心不是真实坐标，补测可能改变区域并产生绕行，因此整局策略不是未知信息任务的全局最优算法，不能把DP最优称成整局最优。

## 4. 到目标附近怎样处理

每次只服务路线选中的一个目标，复用已有 CompletionCostPolicy 的局部费用估计；传入视图只包含策略可见反馈与当前目标，不包含任何源真值。

1. near或包围圆半径不超过20米时直接可靠清除。
2. 半径20—30米时，如中心与现有信息相容，每源最多主动尝试一次中心清除。不是“半径30米就一定成功”；失败反馈用于排除20米圆，随后继续定位。
3. 对其他情况，比较“现在做局部清除尝试”与“去候选点补测再接近”的预计费用。候选包括当前位置、接近路线上距离目标约80/180/350米处及侧向偏移点，均为停下检测。

费用代理沿用已有工作量估计 W：以剩余清除小格数量和可能遍历路程估计后续工作。对有限相容代表位置和-1/0/1度误差情形估计一次测向后工作量下降 G，比较

\[
C_{\rm probe}=\|x-q\|/5+5+I_{\rm switch}+\|q-c_j\|/5+\max(5,W-G).
\]

与直接尝试方案的费用。代表位置平均是决策启发式，不是官方概率后验；小区域中心试清也不附加未经证明的成功概率。

为防止启发式循环，每目标最多24个普通局部动作，超过后接续已有有限清除后备。该后备是兜底，不是默认定位方案；本次140次整局运行均未触发此限额后备。普通费用决策仍可能选择少量小格试清，逐次保留其失败信息。

## 5. 比较设计与已执行检验

- 开发：12个新自建案例（4种布局×3种固定空间误差场），比较四个配置，共48次整局。依据每源均值选定7点、rho=60米，再保存选择记录。
- 后续验证：另24个种子案例，比较选定方案、rho=30米对照和13点对照，共72次整局。没有根据这批结果继续修改策略。
- 压力：8个边界、接近同址/同址、近共线案例，覆盖10/16个源、最小1000米接收半径、零误差及固定极限偏差。
- 既有批次：在原12案例上重跑选定方案，和此前24.54—26.19分钟理想参照及已有策略对齐。

合计56个不同案例、140次策略—案例运行。自建数据与误差分布不代表官方分布；固定偏差加舍入的返回误差可能比题面严格1度多至0.005度，本地几何已包含该余量。没有调用官方演练或正式测试。

新测试核对开放路径DP与六节点全排列（含非原点起步、重复点、空集）、固定点集保留七点、已发现频道继续多点测向。全部完整运行进行逐动作真源保留审计与独立账本核对；有限测试不等于普遍成功概率证明。

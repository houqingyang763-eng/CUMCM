# B 题接口环境检查

本目录用于部署风险排查，**不包含机器狗搜索策略，也不是官方模拟器替代品**。

- `client.py`：标准库本机 HTTP 客户端，四类指令、同 ID 重试、时钟和拒绝处理。
- `test_client.py`：人工响应夹具检查，只验证客户端分支。
- `live_probe.py`：官方演练接口延迟采样；必须先在官方界面确认演练模式。

离线检查（在本目录执行）：

```powershell
python -m unittest -v test_client
```

正式软件就绪后，在本机设置 `CUMCM_ROBOT_ID` 为已登录队号，然后在**演练**界面启动一局，等待接口就绪，再执行：

```powershell
python live_probe.py --practice-confirmed --count 40
```

不在正式测试中运行。该检查会结束当前演练局；只在原点测向，不尝试全清。默认每动作创建本机 HTTP 连接，不要求现实等待虚拟动作时长。尚未实测是否需要持久连接优化。

单局最多 100 次检测；结果写入本目录 `results/live-时间/`。报告包含中位数、P95、总运行时间、虚拟时钟和错误；动作日志不含队号。本次未运行官方接口采样。

部署和风险结论见 `../../docs/B题_环境与迭代风险排查.md`。

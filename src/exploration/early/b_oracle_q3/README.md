# 第三问离线真值参照

先看 [结果](RESULTS.md)。本实验只读取已有自建案例，不接官方程序，也不修改搜索策略。对照批次是 `../b_overnight/runs/q3_sweep_validation/` 的12个案例及其已完成三策略结果；它们已经被查看，属于诊断资料，不是新的未见测试。

## 真值参照知道什么

提前知道全部源的个数、频道和位置，从原点出发，沿直线移动；每次指定频道成功清除收费5秒。不需要测向、不需要测向机切频，不要求返回原点。来源是题目附录2和公开协议所规定的清除计费；每次仍只清一个频道。未知源搜索策略没有获得这些真值。

先构造访问所有源中心的最短开放路径，再在每个中心清除相应频道。中心显然在合法20米清除范围内。因此这是一个可执行参照，而不只是忽略清除动作的旅行路线。它不是对连续20米圆盘访问问题的精确最优解。

## 整数动态规划

设源位置为p_i。以微米为距离单位，对每条中心距离向下取整为整数c_ij，原点到各源距离为c_0j。对已访问集合S及末尾源j，使用

`D(S,j) = min_i[D(S\{j},i) + c_ij]`，初值 `D({j},j)=c_0j`，最终取 `min_j D(全部,j)`。

存储前驱恢复顺序，不加回到原点的边。N≤16，时间复杂度O(N²2^N)，空间O(N2^N)。整数DP精确求解整数化问题；真实欧氏中心最短长度与该整数最优值相差不超过N微米，因此所选真实中心路径也在最优中心路径的N微米范围内。不要把整数化问题精确最优误写成连续圆盘问题精确最优。

距离取整不用浮点sqrt决定边界：把加载后的binary64坐标精确转换为有理数，对缩放后平方距离使用整数isqrt得到向下取整值。源坐标按现有实验文件加载值解释，未声称恢复题外无限精度真值。

## 对任何全清路线成立的下界

令成功清除源i的位置为q_i，则|q_i−p_i|≤20米。原点到首次清除位置至少为`max(0, |p_i|−20)`；两个连续成功清除位置之间至少为`max(0, |p_i−p_j|−40)`。中间即使包含测向、失败清除或额外移动，总长度也不可能更短。

将上述每条距离同样向下取整，求其最短开放Hamilton路径长度L_relaxed。任意真实全清顺序都是这张图上的一条路径，每段真实费用不少于对应边权，故

**T ≥ L_relaxed/5 + 5N。**

单位换算在程序中把微米先除1,000,000。各段圆盘之间的最短间隔未必能被同一组清除点同时实现，所以该图的最优路径不能直接当作可执行清除轨迹。

另用中心最短长度L_center的保守下界构造 `max(0,L_center−20(2N−1))/5+5N`，二者取大。原因是给任意清除路径替换为同顺序源中心路径，第一段最多增加20米，其余N−1段各最多增加40米。该下界也适用于原未知信息策略，因为忽略信息获取只会放宽任务。

设真实已知信息条件下的最优清除成本为T*，执行参照路线成本为U，则有 **L≤T*≤U**。本批上下界相距很小，可用来判断真值效率的量级；不能用它证明未知信息最优搜索策略也能达到U。

# 第三问：利用所有阴性检测形成连续覆盖证明

## 当前判断

**保留此模块，作为自适应选点的通用停止证据。** 它能把普通探测过程中得到的 `no_signal` 用于证明未知频道不存在，不再必须补走全部七个固定参照点。两个新种子的完整自建案例均全清且通过冻结底座的逐步真值审计；这两局共 11 个不存在频道全部提前取得了覆盖证书。

目前只有 2 个开发案例，不能据此声称稳定优于所有基础策略或推断官方成绩。均匀案例总时间基本持平，边缘案例明显改善；选点模块与停止模块合并运行，未做逐项消融。未进入官方正式测试，也未读取官方隐藏案例。

## 题设与证明

题设依据为 `problem/B题.md` 第 11、25、68 行，以及 `problem/附件2.md` 对第三问全向源和 `no_signal` 的说明。源位置属于半径 1800 米的闭圆域，每个源有效接收半径至少为 1000 米，第三问全向接收。因此，某频道在位置 \(q_i\) 返回无信号，可以排除该频道源位于距 \(q_i\) 小于 1000 米的任何位置。实现采用严格小于，主动保留相切边界。

对一个从未发现信号的频道，只需证实

\[
D=\{x:\|x\|\le1800\}\subseteq\bigcup_i\{x:\|x-q_i\|<1000\}
\]

即可确定该频道无源。证明只使用该频道的历史阴性反馈，不读取其他频道的真值、真实接收半径或源位置。

将包围目标圆的正方形 \([-1800,1800]^2\) 四叉划分。对于每个闭方格 \(Q\)：

1. 若其到原点的最短距离大于 1800 米，则整个方格位于目标域外。
2. 若存在一个排除圆，使方格四个顶点到圆心的距离均严格小于圆半径，则整格在该排除圆内。依据为圆盘的凸性，方格是四个顶点的凸包。
3. 否则继续细分或保留为未决方格；不从网格中心有无信号推断整格不存在。

全部叶格均满足前两项时得到覆盖证明。快速阶段把圆内/圆外判据各向保守方向留出 `1e-5` 米余量。**凡是将用于判定不存在的新并集证书，都会再执行独立的有理数复核**：`Fraction` 精确表示输入二进制浮点数，用平方距离比较检查每个叶格；同时递归验证四个子格完整覆盖父格，拒绝漏格、重格、伪造圆索引和被父格吞掉的多余叶格。有理数检查失败将抛出错误，不允许继续标记不存在。

这里的精确性针对代码实际使用的浮点坐标；仍沿用冻结底座对题设、动作坐标和反馈的解释。最多 16 个源的结束规则与原七参照点规则均保留。

## 实现接口

文件：`coverage.py`，未修改 `../b_adaptive_q3/` 的任何文件。

```python
from coverage import CoverageInformationState, CoveragePolicyMixin
from policy import BasePolicy

class CoverageBasePolicy(CoveragePolicyMixin, BasePolicy):
    pass

state = CoverageInformationState()
policy = CoverageBasePolicy()
```

同样可以令 `CoveragePolicyMixin` 排在 `TaskCostPolicy` 前面组合，或直接在主代理统一 `runner.py` 中使用 `coverage` / `coverage_cost`。

| 接口 | 含义 |
|---|---|
| `state.coverage(channel)` | 返回该频道的连续覆盖证书；内部复用相同阴性圆集合的缓存 |
| `certificate.complete` | 所有叶格已严格排除；新并集停止证据必须同时 `rational_verified=True` |
| `certificate.unresolved` | 未排除区域的方格外包；可能包含实际已被覆盖的点 |
| `certificate.statistics` | 叶格数、深度、未决格面积和有理数复核标记 |
| `certificate.to_dict(include_leaves=True)` | 完整证据，可保存圆集合、四叉树叶格及其排除原因 |
| `verify_certificate(certificate, require_complete=True)` | 独立复核完整分割和严格圆内/圆外关系 |
| `state.discovery_points(limit=24)` | 未决格产生的分散候选；混入策略默认只添加 12 点 |
| `state.discovery_gain(channel, q)` | 下一次阴性反馈可以整格排除的面积比例，只作为选点启发式 |
| `state.absence_reasons` | 区分阴性圆并集、七参照点和已发现 16 源的结束原因 |

混入策略保留基础收益；只有原未知频道收益已为零时，才用覆盖面积补足基础 300 米网格看不到的小缺口。候选点、网格点、收益面积均不参与不存在证明。原定位、清除与有限参照回退逻辑保持原样。

默认深度 8，最小方格边长 14.0625 米；若所有未决格中心都已被覆盖，但尚无完整证书，再细化到深度 10、12，最深边长约 0.879 米。未决格中心全部被覆盖不等于覆盖成功，只是触发进一步细化。

## 已运行检查

执行者为 AI，自行核验，不代替人工复核。复现命令均在项目根目录运行：

```powershell
py -3.13 experiments/b_overnight/astra_guard.py check
py -3.13 experiments/b_overnight/test_coverage.py -v
py -3.13 experiments/b_overnight/test_coverage.py --smoke experiments/b_overnight/runs/coverage/new_smoke
```

最后一条要求新输出目录不存在，运行前和每局前检查保护状态。当前 14 项测试全部通过，约 1 秒，关键检查如下：

- 无检测不能判不存在；重复阴性检测没有新增覆盖。
- 中心加旋转 17 度的六点环构成的七点覆盖能够判空，但只命中一个原固定参照点。
- **反例：**六个标准半径 1200 米的环点加 `(999, 0)`，能够覆盖全部原 300 米收益网格点，却漏掉 `(-100, 0)`。证书保留未知，不会跟随采样网格错误结束。
- 七个圆心放在半径 `1000.00001` 米的环上，圆心仍存在极小未覆盖孔；深度上限到达后依然保留该孔，不报告不存在。
- 与目标域边界相切的单圆保持未决；余量足够的严格覆盖可完成。
- 删除证书叶格或伪造已覆盖叶格时，有理数验证器会拒绝。
- 已发现频道不会被本模块的未知频道判空规则删除；16 源上限规则仍生效。
- 旋转环历史形成的小孔，组合策略经两次补测完成，实际只访问了两个原参照点。

开发中曾发现两项测试预期过强并修正：半径仅多 0.1 米的单圆在既定深度上限下不保证能获证；旋转历史下基础选点启发式也不保证一次补测就结束。两者均属于保守检出能力或策略步骤数，未出现错误判空。没有据此放宽覆盖证明。

## 剩余边界

- 此排除规则只适用于第三问全向源。第四问未接收到信号，可能来自定向背面，不能直接使用 1000 米排除圆。
- 四叉树有最大深度，严格覆盖但余量很小的情形可能仍不能获证，会继续探测或走原固定参照点；这是保守遗漏，不是假证明。
- 还没有证明新增候选总能减少路程。两个案例显示“更少检测”和“总用时更短”不是同一指标，应继续用完整任务用时评价。
- 候选点数和面积补偿尚未系统调参。本轮目标是提供可复用的正确结束机制，后续由统一跑局环境比较与任务成本、前瞻策略的组合。
- 模块目前仍在 `experiments/`，未晋升正式代码，不作为论文已经验收的结论。

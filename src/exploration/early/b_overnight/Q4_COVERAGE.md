# 第四问：方向无关的连续覆盖证书

## 当前判断

**数学证书与状态接入已完成，可以保留为第四问的安全证明模块；当前尚未取得整局提速。** 12 项边界测试通过，两个新的完整混合源案例全清并通过位置、计费与真实朝向审计；只把原状态替换成覆盖状态后，两局总时间与原 `Q4DirectionalPolicy` 完全相同。

原因明确：原第四问策略只奖励未知频道的固定锚点检测，两局仍然为不存在频道走齐 37 点。后续要利用此证书提速，需要让选点根据尚未被包围的区域安排自适应补测。当前没有把几何模块的正确性写成速度优势。

## 从题设推出方向无关排除条件

依据 `problem/附件2.md` 第 2.1、2.2 节：有效接收半径至少 1000 米；定向源有效角度为 180 度且包含边界，方向未知。一次无信号可能是位于源背面，所以第四问禁止套用第三问的单个排除圆。

设一个未知源可能在方格 \(Q\) 内，该频道的阴性测点为 \(q_1,\ldots,q_m\)。先选出对整个方格都足够近的测点：

\[
I(Q)=\{i:\max_{v\in\operatorname{vertices}(Q)}\|q_i-v\|<1000\}.
\]

范数关于位置是凸函数，因此这个四角距离判据保证对所有 \(x\in Q\)，这些测点均在最低有效接收半径以内。进一步要求

\[
Q\subset \operatorname{int}\operatorname{conv}\{q_i:i\in I(Q)\}.
\]

那么对任意位置 \(x\in Q\) 和任意单位发射方向 \(n\)，都至少有一个测点满足

\[
n\mathbin{\cdot}(q_i-x)>0.
\]

否则所有测点都在过 \(x\) 的同一个闭半平面，\(x\) 不可能位于其凸包内部。该点既足够近，又位于定向源的发射半平面内，按题设必须接收信号；这与所有反馈都是阴性矛盾。因此整个方格不可能有该频道源。全向源也满足这个排除结论。

实际上，在发射角度包含边界的前提下，源位置属于近测点闭凸包已经能给出更弱的充分条件。实现坚持严格内点和严格距离，主动保留相切、共线等数值边界，不靠近似角度样本判定不存在。

## 连续圆域证书

将 \([-1800,1800]^2\) 四叉划分。每个叶格只允许以下三种记录：

- `outside`：整个方格严格位于源位置圆域外。
- `surrounded`：方格所有角点严格位于一组足够近阴性测点的凸包内。
- `unresolved`：未排除，必须保留。

只有不存在第三类叶格时才可以证明整域不存在。快速阶段使用 `1e-5` 米距离/边界余量；获得新完整证书后，再执行独立 `Fraction` 验证：

1. 四叉树叶格完整覆盖根方格，不漏格、不重格。
2. 对证书中的每个包围测点，逐一以精确二进制有理数检查四角平方距离严格小于 \(1000^2\)。
3. 用有理数重新计算测点的凸包，不相信快速浮点凸包的排序或凸性。
4. 精确检查方格四角位于凸包每条边的严格内侧。

有理数验证失败会抛错，不能标记不存在。精确性针对代码实际使用的浮点坐标，题设、动作坐标和反馈语义仍沿用第四问底座。

默认深度 7，最小格边长 28.125 米；若所有候选格中心均已被包围、但仍未获得整格证明，则细化至深度 9、10，最深格边长约 3.516 米。达到深度上限时，所有未决格继续保留。

## 接口与复用

实现文件 `q4_coverage.py`，复用已冻结 `coverage.Box`，未改第三问覆盖实现、原基础状态或 `q4.py`。

```python
from q4 import Q4DirectionalPolicy
from q4_coverage import Q4CoverageInformationState
from q4run import run_case

result = run_case(
    scene, "directional_coverage",
    policy_factory=Q4DirectionalPolicy,
    state_factory=Q4CoverageInformationState,
)
```

| 接口 | 用途 |
|---|---|
| `q4_coverage_certificate(measurements)` | 对任意同频道阴性测点集合建立证书 |
| `verify_q4_certificate(cert, require_complete=True)` | 独立有理数复核完整证书 |
| `cert.complete` / `cert.rational_verified` | 完整覆盖与已执行独立复核的标志 |
| `cert.unresolved` / `cert.statistics` | 剩余方格外包与计算统计 |
| `cert.to_dict(include_leaves=True)` | 导出测点、四叉叶格及包围测点索引 |
| `Q4CoverageInformationState` | 继承 `Q4InformationState`，保持所有原状态接口 |
| `state.coverage(channel)` | 该未知频道的当前覆盖证书 |
| `state.absence_proofs[channel]` | `q4_local_hull_union` 表示依据本连续证书结束 |
| `state.discovery_points(limit=12)` | 在未决位置的最大未包围角隙方向提出补测点，仅作候选 |
| `Q4CoveragePolicyMixin` | 将这些候选合入既有策略，不改变原收益单位 |

状态只从 `observations` 中取 `no_signal` 位置，**不向 `exclusions` 添加 1000 米圆，不改已发现目标的定位区域**。16 源上限与原 37 点规则仍保留。当前混入类没有给未知非锚点新增“秒”单位收益，不能把它视为已经完成的自适应包围规划器。此次完整对照仅替换状态，未启用候选混入。

## 已运行证据

执行者为 AI，自行核验，不代替人工复核。复现命令在项目根目录运行：

```powershell
py -3.13 experiments/b_overnight/astra_guard.py check
py -3.13 experiments/b_overnight/test_q4_coverage.py
py -3.13 experiments/b_overnight/test_q4_coverage.py --smoke experiments/b_overnight/runs/q4_coverage/new_smoke
```

最后一条要求输出目录不存在，沿用 `q4run.py` 的保护检查、逐步真值审计、真实朝向审计和独立计费。

12 项测试全部通过，最后一次约 1.42 秒。关键区分性检查：

- 单点无信号不能判定附近定向源不存在；实际局部模拟器中位于 `(10,0)`、向东发射的源，在原点返回无信号后依然被正确保留。
- 只有凸包包围、但所有包围点都距源区域过远时不能排除；“近距离”和“方向包围”两个条件缺一不可。
- 共线测点或单侧测点不能取得整格严格包围证书。明确向外发射的边缘位置在单侧阴性历史中仍保留。
- 37 个 900 米三角格点对完整 1800 米目标圆域取得证书：1013 次方格访问、760 个叶格，其中 708 个包围格、52 个域外格；最深仅 6 层。单次生成及有理数复核约 0.088 秒。
- 全部测点旋转 17 度之后依然能够证明不存在，状态只命中 1 个原固定锚点，说明证书不依赖固定点编号。
- 标准数组顺序逐点更新时，在第 36 次阴性检测后即可获得完整证书，整个增量检查约 0.96 秒。这个顺序例子不等于当前整局策略能提前结束。
- 删除叶格、伪造远距离包围点时，有理数验证器均会拒绝。

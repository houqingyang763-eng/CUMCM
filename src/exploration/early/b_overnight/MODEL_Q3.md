# Q3：保守定位状态与预计完成成本

本文对应 `task_cost.CompletionCostPolicy + state.InformationState`，不是尚未实现的方法设想。它在原可执行策略上改变动作排序，继续使用同一套证据、反馈与有限后备。

## 1. 状态保存什么

对每个频道保存：未知/已发现/已清除/已证明不存在，全部测点与返回值，源位置的保守外包，已经排除的清除圆与原始条带小格。机器人另存当前位置、当前测量频道、累计虚拟时间与动作数。

接收到方向后，将源位置限制在该测点的方向扇区与题面源域内。题面返回角误差不超过1°；实现另加0.005°舍入余量，使用1.00500001°。全向场无信号可排除该测点周围1000米的必接收区域。不同记录必须同时成立；离散代表点仅用于排序，不能作为删除真实区域或宣布完成的依据。

首次方向将目标限制在长1500米、总宽52.8米的保守矩形中。沿长边分成50列、横向2行，100个小格各有清除中心。格内最远点到中心小于20米；故沿尚未排除的小格有限尝试能完成清除。一次尝试失败只排除真实反馈支持的范围。

## 2. 为何不只比较测角后面积

目标已经处于20米可清除范围时，再缩小面积通常没有价值。我们估计的是从当前可能区域出发还需多少清除工作。设仍可能的小格数为n，两行蛇形覆盖的估计路程为L米，采用秒为单位的代理：

\[
\widehat W=5+\tfrac12\{3\max(0,n-1)+L/5\}.
\]

能被一个20米圆覆盖时直接取5秒。半程系数1/2是任务排序的启发式，不是位置均匀分布证明，也不是最坏时间上界。

对候选测点q，在当前相容区域选少量代表位置，并模拟误差-1°、0°、1°造成的后续区域，估计工作量下降G(q)。代表位置与误差的平均只是有限近似，不能称官方概率后验。当前实现不给超过1000米、接收不确定的代表位置正收益；每次工作收益还有上限，避免几何近似把单次探测夸大。

## 3. 每次真正如何决策

收到near反馈时，优先到该点清除。否则先看当前位置能否为任何频道省下足够工作：若估计收益至少为本次5秒测量与切换费用的1.2倍，就在原地测该频道。每次仍先取反馈再更新；不会重复测同一频道同一点求平均。

需要移动时，对每个已发现目标比较以下整段费用：

| 行动方案 | 用于排序的预计成本 |
|---|---|
| 已能保证一次清除 | 到保守包围圆心的移动秒 + 5 |
| 立即开始小格试清 | 到最近仍可能清除格的移动秒 + 当前工作估计 |
| 先到q测向再接近目标 | 到q移动秒 + 本次测量切换秒 + q到当前区域中心移动秒 + max(5, W−G(q)) |

选择估计最低的一项，只执行其下一动作，取得实际反馈后重新计算。测后目标中心还用测前中心近似，因此第三项不是精确未来成本。小格试清可能失败，但失败不会丢失目标；它产生新的排除信息。

候选点包括当前点、保证发现的参考点、区域中心、长轴的侧向偏移、目标附近接近点，以及相邻目标中心的折中点。位置是根据当前信息生成的，不是事前固定整局点表。

当没有已发现但未清除的目标时，用未知频道覆盖收益与费用选取发现动作。当前位置的共享测量也可为未知频道增加信息。未达到结束证据时绝不因已经清了10个就停下。

## 4. 稳健部分怎样继承

启发式累计到6000虚拟秒或600动作后，转入有限后备：补足七点发现证据，然后每个目标连续完成自己的剩余清除格。它接续已经获得的所有信息；不是重新从零开始一套算法。

Q3中心加半径1200米正六边形的七点，覆盖R=1800米源域，最差最近距离约968.90米，小于最小接收半径1000米。每个未知频道在这些点全阴性才有相应不存在结论；已确认源数达到题面上限16时也可解决余下未知频道。

结合实际跳转、预算越界一步等费用，默认代码的宽松全局虚拟时间界约64410.48秒。详见 `FALLBACK_BOUND.md`。这界服务于有限完成保证，不代表典型效率；典型性能需看完整实测。

## 5. 可以继续改哪里

`Q3SweepPolicy` 只改变共同发现与远处清除的先后时机：先积累多频道信息，再调用这里的Completion。它与本方法共享状态、候选工作估计与后备，不需要合并两套定位系统。已执行的新12例平均快4.78%，但一例多968秒；因此下一步应解决该反例的多余移动，而不是增加未经证明的复杂模型。证据见 `SWEEP.md`。

研究过的完整前瞻模拟、参数筛选和共享移动收益均没有自动优于当前默认。当前的实用原则是：几何与结束判断保守，行动排序可以改进，所有提速主张回到同批完整案例核验。

日期：2026-09-11。状态：本地方法已实现并冻结，可交给主代理做独立组合验证。没有修改原 Q4 策略、原覆盖证书或模拟器。

**保留这一方向。** 4 个新开发布局中，原 `Q4DirectionalPolicy` 配联合状态后，全部 49 个源仍清除，平均虚拟时间由 10335.82 秒降为 9501.64 秒，约减少 8.07%；失败清除由 177 次降为 23 次。4 局均改善，但近共线局只改善约 0.20%，不能把这组小样本写成一般提速保证。

核心变化是：原状态主要把朝向用于候选评分，这里把**整块位置与所有可能发射方向都不相容**变成可靠删格证据。既不以几个代表点投票删格，也不把 Q4 阴性直接变成 1000 米排除圆。

## 1. 连续小格的方向外包

设某个尚可能含源的清除小格与当前几何约束交成凸多边形 \(P\)。发射朝向为 \(\phi\)。对测点 \(q\)，定义从可能源指向检测点的视线角集合

\[
A_q(P)=\{\arg(q-s):s\in P,\ s\ne q\}.
\]

这里不是源的示向度，而是源看向检测点的方向；两者相差 180°。实际测角误差已由原状态的扇形裁剪体现在 \(P\) 中，这一步不能再次把读数当真方向。

当 \(q\) 在 \(P\) 外部时，凸多边形的连续视角由顶点极射线界定。代码将顶点的 \(\arg(q-v)\) 排序，找最大角度空隙，其补弧覆盖 \(A_q(P)\)。如果测点在格内、边上、距边界不超过 \(10^{-5}\) 米，或者数值结果出现大于 180° 的视角，则直接使用整圆，避免在退化位置强行推断方向。

对阳性检测点 \(p\)，相容的发射朝向必须属于

\[
\Theta^+_p(P)=A_p(P)\oplus[-90^\circ,90^\circ].
\]

这里 \(\oplus\) 表示圆周上的角度扩张，结果宽度达到 360° 时取整圆。

## 2. 哪些阴性反馈可以限制朝向

若某个阴性点 \(q\) 对**整格所有可能源位置**都有接收距离保证，则无信号不能由距离过远解释。此时：

1. 该整格中的全向源解释不可能；
2. 定向源的朝向必须避开 \(q\) 所在的发射半圆。

所需距离保证复用 Q2 的 `guaranteed_reception`，但在这里仅解释为“距离不超出接收半径”。即对所有 \(s\in P\)，

\[
\|q-s\|\le R_{\min}(s),\qquad
R_{\min}(s)=\max\{1000,\max_{p\in H^+}\|p-s\|\}.
\]

历史阳性距离仍提供半径下界，不因 Q4 的定向性而失效。这个证书不是仅检查格中心；内部使用 Q2 已核验的半平面残余裁剪。因此，距格中某些位置超过 1000 米的阴性点也可能提供可靠朝向约束。

一旦获得距离保证，阴性允许的朝向外包可写成

\[
\Theta^-_q(P)=\bigl(A_q(P)+180^\circ\bigr)\oplus[-90^\circ,90^\circ].
\]

题面发射边界包含 ±90°，真实阴性应排除这些边界。本实现仍把允许集写为闭区间，并向外增加 \(10^{-6}\) 度，因而多保留临界方向，不会因为边界舍入误删真源。0° 与 360° 的闭端点在求交前补齐等价表示，防止把同一个朝向错判为不相交。

## 3. 整格什么时候才能删除

令所有阳性约束与具有整格距离证书的阴性约束相交：

\[
\Theta(P)=\bigcap_{p\in H^+}\Theta_p^+(P)
\cap\bigcap_{q\in H^-_{\rm distance}(P)}\Theta_q^-(P).
\]

每次观测的角度外包分别允许源在整格中变化，这主动放松了“各次观测必须来自同一个位置”的耦合。因此：

- \(\Theta(P)\ne\varnothing\) 只表示外包尚不能排除，不证明一定存在共同可行源；
- 若全向解释已被至少一个可靠距离阴性排除，且 \(\Theta(P)=\varnothing\)，则整格没有任何允许的源类型和方向，可以安全删除；
- 即使定向交集为空，只要全向解释仍可能，就保留整格。

这一判断来自连续格上的外包。数值代表点仍可用于策略评分，但不参与删格证明。

一个构造检查使用真实源 \((300,0)\)、发射方向 0°、半径 1500 米，阳性点 \((1450,-190)\)、\((1450,190)\)，其示向度误差分别约 +0.95°、−0.95°；阴性点为 \((150,0)\)。原角度/距离位置约束同时容纳真实源和 \((0,0)\)。加入联合约束后，包含 \((0,0)\) 的不可能小格被删除，而真实源仍保留。该例直接验证状态更新确实产生了新删格证据。

## 4. 状态接入与有限后备

`JointChannelState` 继承冻结 `ChannelState`，复用原 100 格框架、原无向清除排除圆和缓存失效机制。在 `possible_cells()` 中应用联合证书；`compatible()` 同步要求位置落在保留格中，使候选代表点也看到收紧后的状态。

已证明不可能的格编号保存在 `joint_excluded`。首次测点、首次示向度和格框不变；后续位置约束只会收紧，已证空格不会重新变成可能，所以该记录可以持久使用。若一个已发现源的全部格都被排空，程序抛出不相容异常，不会把它静默标成“已清除”或把空区域当半径零圆。

本轮未更改原 `Q4DirectionalPolicy` 的选点公式和后备逻辑。联合状态仅安全跳过某些剩余格，故有限 100 格清除及其原虚拟时间上界仍可保留。它本身不取代未知频道的完整发现证明。

### 两个可调用状态类

```python
from q4 import Q4DirectionalPolicy
from q4_joint_state import Q4JointInformationState, Q4JointCoverageInformationState

# 第一轮4布局对照使用此类：原37点发现 + 已知目标联合状态。
state = Q4JointInformationState()

# 后续推荐组合：未知频道连续覆盖 + 已知目标联合状态。
state = Q4JointCoverageInformationState(
    coverage_depth=7,
    coverage_refinement_depth=10,
)
```

`Q4JointCoverageInformationState` 完整继承冻结 `Q4CoverageInformationState` 的 `update`、`coverage`、`discovery_points`、`q4_anchors_missed` 和 `absence_proofs`，只替换频道状态类型。已与覆盖代理核对：精简锚点策略不需要其他构造参数，可直接使用

```python
q4run.run_case(
    scene,
    policy_name,
    trace_path,
    policy_factory=selected_anchor_policy,
    state_factory=Q4JointCoverageInformationState,
)
```

精简发现点 + 连续覆盖 + 联合状态的**完整组合表现仍待主代理独立验证**。本轮只增加了两项必要接口检查：连续覆盖仍能结束不存在频道；已发现频道仍能联合删格且保留真源。没有把它们写成组合整局成绩。

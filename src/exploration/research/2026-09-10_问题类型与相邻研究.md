# 2026 B 题：问题类型与相邻研究初查

日期：2026-09-10。用户目的：建立基础认知，了解问题所属类型和类似问题如何求解。

本轮检索通用原始研究和相邻机器人应用，没有搜索本届 B 题答案；没有编写算法、开展实验、启动模拟器或确认正式路线。下述迁移判断是本题适配分析，不是原论文对本题的保证。

## 类型判断

总体属于机器人主动搜索与定位，以及不完全信息下的序贯决策。细分为：仅方位目标定位、有界误差集合估计、主动测量选点、传感覆盖与巡检路径、信息驱动路径规划。清除带来服务动作和状态改变，不能仅用定位精度或信息量替代任务目标。

## 已核对的重要研究

### 1. Sensor Placement and Selection for Bearing Sensors with Bounded Uncertainty

- Tokekar 与 Isler，ICRA 2013。
- 原文：https://tokekar.com/pubs/tokekar2013asensor.pdf
- 已读正文的问题定义、相关工作和主要结果说明。
- 测角噪声未知但有界；每次观测产生包含目标的扇形；交集表示位置估计，以最坏情况下的面积或直径评价。研究方形区域内的传感器布设和选择，并分析三角网格方案。
- 本题用途：第一问区域建模、第二问最坏情况选点评价。集合估计无需擅自补入误差概率分布。
- 限制：原文布设问题没有本题的有限接收范围、未知发射方向、频道和清除代价；不能照搬布点定理。

### 2. Algorithms for Cooperative Active Localization of Static Targets With Mobile Bearing Sensors Under Communication Constraints

- Vander Hook、Tokekar、Isler，IEEE T-RO 2015。
- 作者入口：https://tokekar.com/vanderhook2015algorithms.html
- 正文：https://tokekar.com/pubs/vanderhook2015algorithms.pdf
- 已读问题定义、测量与移动成本、在线策略和估计条件部分。
- 同时计算行走与测量时间，在给定定位精度目标下选择观测位置与测量次数；包含单机器人情形。通过先研究已知真位置的离线参照，再构造未知真位置下的在线分阶段策略。
- 本题用途：第二问及第三问单源定位过程，理解近一点再测与远一点多测的取舍。
- 限制：概率估计与独立噪声等条件不等同于题面的有界、同地点固定误差；原文近似保证不能直接移植。多机器人通信部分对本题不是重点。

### 3. Cautious Greedy Strategy for Bearing-Only Active Localization: Analysis and Field Experiments

- Vander Hook 等，Journal of Field Robotics 2014。
- 正文：https://tokekar.com/pubs/vanderhook2014cautious.pdf
- 已核对研究目标、Gaussian/EKF 表示及相关保证的条件。
- 无线电标签定位应用；主动选取测向位置，并处理天线前后方向歧义造成的估计问题。
- 本题用途：进一步了解主动定位的实际应用。原文方向歧义不是本题已给观测的一项条件，不能新增到本题中。

### 4. Coverage Path Planning: The Boustrophedon Decomposition

- Choset 与 Pignon，1997。
- 研究机构页面：https://publications.ri.cmu.edu/coverage-path-planning-the-boustrophedon-decomposition
- 原文：https://www.ri.cmu.edu/pub_files/pub4/choset_howie_1997_3/choset_howie_1997_3.pdf
- 核对摘要和原文介绍：将区域分成可往返覆盖的单元，再通过单元邻接图安排遍历。
- 本题用途：理解完整覆盖和优化行走是相互关联但不同的任务。机器狗能远距离感知且只能停下检测，应改成离散检测点的传感覆盖；不能直接套连续扫地轨迹。

### 5. Viewpoint placement for inspection planning

- Gospodnetić 等，2021 在线发表，2022 卷期。
- 原文：https://link.springer.com/article/10.1007/s00138-021-01252-z
- 已读第 3 节候选要求和第 5 节优化：生成候选观察位置，计算满足距离、角度等条件的可见关系，再选取覆盖观察对象的子集；采用下一最佳观察点的贪心选择。
- 本题用途：把候选检测点与能保证检测的潜在状态建立覆盖关系，再安排访问顺序。
- 第四问需覆盖潜在位置及发射方向的组合；这是迁移设想。文献中的已知物体表面与本题未知源状态不同。离散状态覆盖不能直接证明连续全域覆盖。

### 6. Adaptive Informative Path Planning with Multimodal Sensing

- ICAPS 2020。
- 原文：https://arxiv.org/html/2003.09746
- 已核对第 3 节成本和观测模型、第 4 节 POMDP 与在线规划。
- 在移动和使用传感器都消耗预算的环境中，维护信念、联合选择移动与感知动作；采用 POMCP 在线搜索，配合预算约束剪枝及成本收益启发式。
- 本题用途：理解每一步根据已有信息重新决定去哪里、测什么、是否继续测的统一框架。可以借鉴有限步前瞻，而不一定实现完整概率求解器。
- 限制：原文已知随机观测模型、预算内最大期望效用与本题确保全部清除后最小时间不同；必须重新定义状态、动作、结束条件和目标。

### 7. Efficient Decision-Theoretic Target Localization

- Dressel 与 Kochenderfer，ICAPS 2017。
- 页面：https://ojs.aaai.org/index.php/ICAPS/article/view/13832
- 原文：https://ojs.aaai.org/index.php/ICAPS/article/download/13832/13681/17350
- 核对摘要：采用依赖信念的奖励，研究 SARSOP 和 POMDP-lite，并应用到六旋翼无人机搜索无线电源。正文已取得，但本轮没有逐式审查求解器。
- 本题用途：证明概率序贯规划与无线电源搜索存在真实研究联系；不能据此宣称全清保证。

### 8. Active localization of multiple targets using noisy relative measurements

- 2020 预印本：https://arxiv.org/html/2002.09850
- 已核对噪声与观测条件。采用强化学习处理多目标主动定位；原文使用 Gaussian 测量噪声，并在每步接收所有目标可区分的观测。
- 本题限制：一次仅检测一个频道、未知数量和定向盲区与原文不同。作为后续线索保留，不列为首选实现。
- 2026-09-10 补充核对：引言明确所有目标起初可观测，不处理搜索；§V-B 采用 TD3 学习移动策略。该文确有跨交互改进策略的思想，但不能直接解决本题的未知源发现。详见[策略迭代专题](2026-09-10_用模拟成绩迭代选点策略.md)。

## 当前判断

最贴近题面且适合先理解的是有界误差集合定位、计入测量成本的主动定位、传感覆盖与巡检规划。信息驱动路径规划/POMDP 是更统一的决策视角，但需要额外概率模型，且优化信息不自动等于优化清除时间。当前没有确认任何现成论文能直接解决本题全部条件。

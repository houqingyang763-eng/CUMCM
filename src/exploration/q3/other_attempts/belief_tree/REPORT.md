# 统一行动与多步信念树：停止当前候选

2026-09-12。仅本地自建仿真，未运行官方测试。结论：保留旧F3作为当前研究候选，本轮U1/T3/M3不替换它。用户随后要求终止明确无法继续的实验并分析提升方向，已核对没有本轮运行进程；没有启动新一轮优化。

## 1. 实际做了什么

- U1：从空白公开状态起，每次反馈后统一比较原地检测、异地检测、所有已知源的清除尝试，没有强制两站；一层条件粒子树，F1完整续行估值。
- T3：同一接口、后验、有限候选和预算，搜索三条原子指令后的反馈分支。每次48条模拟、16个联合世界、每频道256个提议点。
- M3：唯一主要结构修正。增加由搜索自主选取的整站扫描动作；选中后扫完该站有效频道再规划。原子候选仍存在；三层可以跨越多次停留，但并非必须使用宏动作。
- 开发期修正了同样的无信号反馈被拆成不同树节点的问题，按精确反馈合并并保持出现次数权重；修复模块同名导致的启动导入错误。这些属于实现修正，不计作性能改进。

没有继承旧W/G加权分数，没有用隐藏真值决定动作，没有把抽样无剩余源当作公共全清证明。具体定义见[MODEL.md](MODEL.md)。

## 3. 为什么退步

### 3.1 单次移动变短，但移动次数更多

F3平均28次移动，M3平均39.25次。按所有移动合并计算，平均一次移动分别85.65和67.56秒。M3相对F3总移动多4.226分钟，扫描多0.323分钟，切频多0.013分钟，失败清除少0.019分钟，总计多4.543分钟。主要损失是路线组织，不是几秒切频本身。

在最坏的均匀/偏置330011中，M3额外移动9.116分钟、扫描4.667分钟、切频0.867分钟。该例同频道30米内测量有37对，F3为0对；这只是近邻标记，未把所有这些观测直接判成无效。可确定的是新增停留和扫描没有换来整局收益。

### 3.2 提前清除未同时解决未知频道覆盖

最后一次实际清除之后的查漏：F3平均1.515分钟，M3平均7.998分钟。这部分是总成本的另一种阶段分解，与上面的移动/扫描分解重叠，不能相加。

直线/偏置330020：M3在步骤134、33.681分钟清掉最后实际源，但之后还要25.613分钟证明没有遗漏，最后59.294分钟；F3最后实际清除即结束，共55.609分钟。M3“很早开始清除”的部分成立，全清结束时的收益却丢失了。算法当时不知道真实总数，不能事后改成33.681分钟停止。

直线/平滑330019也有18.263分钟的末尾查漏。必须把剩余覆盖需求作为整条执行路线的任务，而不能只在短前瞻后反复把它交给尾部策略。

### 3.3 当前估值没有可靠地区分候选

初始公开状态的32个共同世界复算中，多个内侧候选平均一层续行费用只差12.9—74.8秒，而相对该批最佳候选的配对标准误约42.5—61.7秒。这支持“当前证据无法稳定区分这些位置”，并非证明它们真的等价，也不能把同一检查的最佳候选当作真最优。

原树在48条模拟下大约只展开14个根动作，每个动作只有少量观测分支。独立可行的反事实小题证明三层结构确实可利用后续反馈，但不证明在本题预算下有足够统计精度。树叶完整调用F1是合法的rollout近似；使用旧尾部本身不必然导致失败，问题是本实现没有精确估值、完整展开或可继承的改进保证。

M3八例共556次实际搜索，14次有限后验提议池耗尽并退回公共F1，集中于两例偏置场景。对应真实状态没有被改成“无源”；全清与账本复核通过。这是数值稳健性问题，但其余六例无此异常且多数仍退步，因此不能把全部失败归因于这个异常。

## 4. 停止后最推荐研究什么

推荐方向是**按频道的完整覆盖—清除路线联合规划，概率用于选择和更新少量完整方案**。它仍保留反馈适应能力，不重新规定必须两个初始点。具体数学设计及与旧实现的区别见[NEXT_DESIGN.md](NEXT_DESIGN.md)。

先检验当前已观察状态上的确定性路线是否能实质缩短，再检验概率估值能否正确排序候选。未通过这两项，不扩大树深、粒子数或开展价值网络训练。新方向目前只有基于证据的设计，没有新性能结果，也不承诺达到40—50分钟。

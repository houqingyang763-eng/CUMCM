# 实现定义与近似边界

本版是条件粒子信念树，不是论文PFT-DPW的逐行复刻。目的：在同一公共状态下开放原子行动，并比较一层与三层反馈前瞻。研究依据见[上一轮调研](../../research/2026-09-12_进一步优化与POMDP可行性.md)。

## 1. 概率与公共状态

沿用均匀位置、固定接收半径U[1000,1500]、N在10—16均匀、等概率频道子集的工作假设。新地点的角误差用固定哈希场近似独立U[-1°,1°]，相同地点严格复用已有反馈。该分布不声称来自官方；平滑、偏置误差属于失配压力。

已知源的位置提议来自保守几何区域，未知源来自阴性覆盖后未决格。范围观测权重是相容半径区间长度；方向权重使用舍入区间[读数-0.005°,读数+0.005°]与真实角度±1°的交长。同一地点的相同观测只计一次。存在性按照N的约束联合抽样，不允许各频道独立产生超出16源的世界。

未变化频道的有限提议池按该频道的唯一历史缓存，新行动后只重建变化频道的池。不同世界仍独立抽取池中位置与半径；有限池不是全体可能区域，不承担排除证明。首次256提议耗尽会触发后备，不作无源判断。

树节点另外保留公开CoverageInformationState，查漏结束沿用连续覆盖证据和最多16源的公共上界。即使某个抽样世界已没有剩余源，也必须模拟公共查漏到完成。已增加相应检查。

## 2. 行动集合

每次反馈后生成：旧F1下一动作；当前位置所有已发现频道和未知历史组代表的测量；全部已发现目标的两侧横向测点；已有两/三圆覆盖方案各圆的清除尝试；包围半径≤80米的中心试清；未知区域的6个候选；无已发现目标时另加原点和几个不同距离的初始候选。

完全同历史的未知频道在当前对称先验下可交换，只保留当前频道或最小编号代表。该对称性只在本版假设下使用。原地保证能清除的动作先执行，因为这5秒迟早要支付，而立即执行不增加路程或测向切频。能够证明必为无信号的重测以及同点重测剔除。

这是有限候选近似，不是整个连续行动空间的最优搜索。半径80米仅是第一版中心尝试的候选范围，不是题目要求或全局有效剪枝。未知点不能借其他频道的阴性记录直接排除。原子清除失败后，下一步仍可重新选择检测或其他清除点。

## 3. 树搜索与全程成本

节点行动数按ceil(2*sqrt(访问次数+1))逐步增加，最多枚举完候选；已展开行动以最小化平均费用的UCT选择，探索系数为180虚拟秒。该参数仅分配模拟资源，不加入最终任务费用。观测分支数按ceil(sqrt(该行动访问次数+1))限制。

每次新模拟观测，计算父粒子似然及有效样本量，再从整个公开新历史条件抽样生成新的节点信念。这样避免连续角度下只保留一个命中粒子；仍有有限提议池误差，不宣称精确贝叶斯更新。

完全相同的反馈键(类型、精确舍入角度、清除结果)共用节点；观测重复产生次数作为重用抽样权重。不能把不同角度只因接近而合并。最初未合并版本已在开发期停止，部分轨迹不计作完整实验。

累计成本只有移动距离/5、测量5、切频1、成功清除5/失败3。三层意味着三条原子指令，不一定三个不同测点。树外真实执行一条指令后重新搜索。

树叶采用完整F1续行：从条件世界生成反馈，但F1仅见这些反馈。每次叶估值抽一个世界并完整执行到公共完成；同节点同世界结果缓存。多个模拟的平均近似叶价值，不是把未知源真实最短路线当成免费信息。遇到尾部未完成不返回零，整次规划记录异常并执行公共后备动作。

因此，本版仍受尾部F1质量、有限模拟数、原子时域过短、先验失配和候选限制影响。尤其20频道共享扫描可能比三条原子动作更长；不得将本版失败直接推广成POMDP无效。

## 4. 对照与记录

U1与T3共用状态、先验、候选、尾部和模拟预算，只改变搜索深度。F3和scan7_r60按原代码运行。首次完整对照应看all_clear及虚拟分钟；CPU耗时单列，超出官方现实截止时间的版本不声称可正式部署。

每次行动有公开前后状态与独立费用；搜索日志包含原动作、选中动作、评估的候选、访问/分支次数、最低有效粒子数、尾部调用和异常。audit.py用独立环境重放全部反馈并按标量公式重算费用。模拟不完成、被开发期主动停止、已完成但退步分别记载，不混为一个失败率。

## 5. 单项结构修正M3：允许整站扫描

开发期原子T3的前段出现只测少数频道即移动、相邻点再查同频道；32共同世界的一层重估显示初始内侧候选的差值小于抽样不确定性。另一个可明确定位的限制是三条原子指令无法包含一次最多20频道的完整停留。为隔离这个限制，增加M3对照，原U1/T3继续保留，不能把尚未完成的T3先宣判失败。

M3保留全部原子候选，并在每个可测位置后插入整站候选：按当前频道优先、其余频道号顺序，扫描所有尚未清除/排除、未在该点测过、且不能证明冗余的频道。选择宏动作后连续执行该站，结束再规划；不是每个频道后重选测点。期间公共证明变为不必测的频道会跳过。它是有限的半马尔可夫POMDP行动扩展，主动放弃站内任意中断以换取更长空间前瞻；不是由人强制第一/第二站。

树内逐条产生整站反馈、更新公共状态、累计全部移动/切频/扫描成本，以联合反馈建立分支，再由完整历史条件抽样。实际接口仍只输出一条合法measure/clear，队列继续动作单独标记；树估值与队列执行的一致性已在有信号、无信号混合的完整20频道小例中核对。

M3与T3同为48次模拟、16个条件世界、三层、180秒探索系数和同一F1尾部，唯一主要设计差异是增加整站行动及其提交语义。增加候选会改变有限预算下的展开次序，这也是该实现的一部分。所有原子候选仍存在，但同预算未必全部展开；不能据此宣称M3性能必然不差于T3。

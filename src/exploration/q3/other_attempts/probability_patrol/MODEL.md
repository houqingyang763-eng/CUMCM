# 两点起搜与途中补测：本轮实际实现

本文件解释已运行版本，不把研究建议混写成已实现功能。正式输入只读，本轮只用自建第三问环境。

## 1. 已确认的题目约束

来源：`problem/B题.md` 问题3、附录1–3。源位置在半径1800米的圆域内，总数10–16，20个频道且每源频道互异。
每源接收半径固定且在1000–1500米之间。误差全局限±1度，同地点重复测量的误差不变。
速度5米/秒；每次测量5秒，切换测向频道1秒；清除成功5秒，失败3秒；清除不改变测向频道。
20米内可清除，5米内测量给near。目标是全清后总时间短，不允许以低漏检概率代替全清。

## 2. 初始两个点：概率量与完整策略分开评价

令源位置为X，固定接收半径为R，测点为p1、p2，di=|X-pi|。
在位置按面积均匀、R独立均匀于[1000,1500]的工作假设下，令

\[
S(d)=\operatorname{clip}((1500-d)/500,0,1).
\]

则至少发现一次概率为 `E[S(min(d1,d2))]`，两点都可见概率为 `E[S(max(d1,d2))]`。
不能把两次可见按独立半径相乘；同一个R在全部观测中共用。双点可见不等于有足够定位精度，后者用真实测角反馈及保守几何交集另算。
固定点和独立同分布源假设下，N源期望发现数为Nq、全部发现概率为q^N；不适用于任意自适应选点或未知官方分布。

离线先研究覆盖、交会、短行程等指标，再把少量候选接到完全相同的后续策略，以实际全清时间的样本均值比较。
没有自定义“发现×权重+精度×权重”的旧综合评分，也没有声称有限候选搜索得到了全局最优。
第二轮三个布局统一固定旋转30度；第四轮只有三个预先固定的相邻外围布局，均保留失败结果。

冻结版本采用p1=(-129.903811,-75)、p2=(519.615242,300)米，从原点直接前往p1，无原点测量。
每点逐频道扫描未终止频道，优先保留当前频道以节约切换。两点结束后进入清除与覆盖共同安排。

## 3. 公开几何状态与局部清除

复用`b_adaptive_q3`的外包圆多边形、带1.00500001度舍入容限的方位楔形、阴性排除圆和保守包围圆。
任何概率估计都不参与删除真实几何可行区域。

局部规则保留首版：

1. 若当前位置的20米圆包含整个可行区域，立即清除。
2. 包围圆半径不超过20米，去圆心清除；半径20–30米每源允许一次圆心尝试，失败正常计费并排除20米圆。
3. 优先利用当前位置尚未测过的视角；不能不断向估计中心靠近而不形成交会角。
4. 区域仍大时，以其最长顶点连线为长轴，以保守包围圆心为基准沿长轴垂线两侧产生候选，选路程较短一侧。偏移为半径的一半，限制30–300米。这是明确的几何启发式，不是论文原公式的照搬或最优证明。
5. 达到局部预算后，用30×26.4米的有限可行格逐格尝试清除；该格的半对角线小于20米。格子用于实际可行回退，不用于估计未来工作量。

新的策略没有继承`BasePolicy`、`CompletionCostPolicy`或`CoveragePolicyMixin`，也不调用旧W/G评分。

## 4. 第三轮：清除任务与查漏任务共同排路

输入只有当前公开状态。为每个已发现源构造一个当前服务位置：可清除时为包围圆心，否则为上节横向补测位置。
这些位置必须服务；未知频道的剩余区域需要通过一部分实际扫描位置覆盖。

`covering_route.py`的执行步骤：

1. 取所有未知频道**共同已经得到**的阴性观测，构成规划的公共已排除区域。不会把A频道的阴性证据借给B频道。
2. 将服务位置纳入开放路线，用200米内部网格、3度边界点及实际未决区域见证点构造离散覆盖要求。
3. 优先利用这些服务位置承担未知扫描；不足时添加可选扫描站。新站的移动增量按`|a-q|+|q-b|-|a-b|`计算，开放末端只加`|a-q|`。
4. 使用两个有界构造器：覆盖数量优先；以及单位新增覆盖的插入秒数。删除冗余未知扫描标签，保留服务任务，再作开放路径2-opt。
5. 两个构造结果按“计划移动时间+必要未知扫描费用”选较短者。代码中未知每频道暂按6秒计价，实际运行仍严格按5秒检测和真实切换次数收费。
6. 离散覆盖不能结束规划：把拟执行的扫描圆与公共已排除圆送入连续覆盖证明，未闭合则补见证点。此时证书仅表示**若未来检测均为阴性，则可闭合覆盖**，绝不改实际频道状态。
7. 执行一个到达动作及该站共享扫描批次，收到真实反馈后重排。未指定承担未知扫描的服务站只作必要已知源测量，不扫全部未知频道。

计划代价没有计算所有未来补测、定位变化和新发现目标的清除，因此它是路线构造代理，**不是已验证的完整期望全清时间或在线ΔT函数**。
每站多个频道仍依次停测，移动中不测量。重排发生在共享扫描批次结束等决策边界，不是每个频道反馈之后都立即重排。

连续不存在证明由`coverage_state.py`复用的保守四叉树完成；宣称完整覆盖之前用有理数验证各叶格在某个真实阴性1000米圆内或目标圆外。
已实际发现16源可依据题面上限排除其他未知频道。除此之外，只要存在尚未排除的频道/区域就不能退出。

## 5. 已实现但未接入控制器的概率函数

`belief.py`给出某未知频道**条件于它确实存在源**时，下一点的发现概率。只条件于该频道已经收到的全部阴性反馈，不访问真值。

令历史阴性点集为H，

\[
U_H(x)=\min(1500,\min_{p\in H}|x-p|).
\]

在上述均匀工作假设下，

\[
P(\text{发现于}q\mid H,\text{该频道存在})=
\frac{\int_D[U_H(x)-\max(1000,|x-q|)]_+\,dx}
{\int_D[U_H(x)-1000]_+\,dx}.
\]

R已解析积分，位置用固定随机样本积分；不同候选共用样本。返回标准误、有效样本量和历史阴性似然。
同一点重复检测的新增发现概率严格为0。零采样相容质量报错，不能判该频道不存在。
历史阴性似然满足`Z_new=Z_old*(1-p)`，但Z不是该频道存在概率，更不能当作剩余源数或全清证书。

该函数已通过解析特殊例和独立联合(X,R)蒙特卡洛核对。它保留为概率诊断与研究资产，**没有参与本轮冻结策略选点**。
完整在线观测价值需要一致的后续策略及未发现源模型；本轮没有把未经校准的预演分数接入控制器。第四轮修正未达目标后按停止规则结束，没有继续添加这一复杂层。

# AI1：第三问优化尝试总记录

整理日期：2026-09-12。维护者：**AI1**。本目录仅由AI1写入；AI2、AI3请分别使用自己的编号目录。本目录是证据汇总，不是新的策略版本或正式提交。

## 当前结论

本对话主线从“七点完整巡查”逐步走到“两个初始测点、反馈选择第二点、途中共享补测、允许两三次覆盖清除”。**当前保留的研究版本为F3；F4复查层没有显示增量收益，未采用。** 这是AI1主线的结论，不代表其他AI独立路线的状态。

- 两批各24例中，F3平均55.735、55.756分钟，同批baseline分别63.773、64.362分钟；合并48例的描述性均值为55.745对64.068分钟，平均省8.323分钟。
- 未达到此前“相对baseline平均至少省10分钟、平均整局40—50分钟”的验收目标。不能因个别场景达到30—40分钟便宣布达标。
- 最稳定的小改动是F1：删去已能证明冗余的阴性测量，两批各平均省约27秒。更复杂的选点与清除方案收益更大，也出现数分钟退步。
- 最新重算发现：F3第二批24例，最后一次成功清除后平均仍花3.130分钟，其中移动2.456分钟。**如何用更短路线、少量必要频道补齐未覆盖区域，是尚未完成的新研究方向。** 目前没有该新方案的整局实验成绩。

## 归属与证据范围

本目录覆盖本对话可追溯的优化主线：前置基线与评价反思、中心逼近失败、概率两点巡检R1—R4、自适应第二站、F1—F4、随机轨迹复查、评价指标和查漏重思考。早期项目已有基础策略与基线列为前置参照，不冒称为此次归档新增成果。没有将`belief_tree/`、`clearability/`等其他独立路线的结果归到AI1名下，也没有修改它们。

原报告、代码、种子和动作流水均留在原目录；这里用相对链接引用。历史Sweep仅在解释旧实验时保留，当前主验收参照仍是scan7_r60。不存在把不同批次baseline固定成64.02分钟再相减的做法。

本次按逐局数据读取456条“策略×案例”结果，核对同案一致性和费用加总；另重算第二批六版本共25,700条动作的路程、操作费和累计时间。**这些是重新汇总既有运行，不是新增456个独立场景，也不是重新运行模型。** 过去的几何/全清核验有各原实验记录，本次不冒称重新证明了全部策略。

全部性能属于所列自建仿真；本次未操作官方模拟器、未启动正式测试、未修改正式算法。分组结果不是官方分布推断。源数、布局、半径、误差存在混杂，不能用分组均值直接证明因果关系。

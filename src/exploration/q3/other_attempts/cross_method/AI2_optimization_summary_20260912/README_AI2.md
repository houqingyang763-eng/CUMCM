## 归属与边界

覆盖本对话可追溯的完整路线：**前置基线与中心逼近教训 → 概率两点巡检 → 自适应第二站 → 用户看图诊断及F系列 → 文献/知识库调研 → AI2统一行动信念树 → 停止与提升分析。** 其中共同前序与AI1归档有重合，不宣称其为AI2独占原创。AI2后续重点是 `belief_tree/`；未将AI1后续独立查漏诊断或其他会话的 `clearability/`、`boundary_penalty/` 等成果归为本次尝试。

本次独立从原始JSON和动作日志重建统计，不读取AI1的metrics作为成绩来源。只写AI2目录并追加AI使用记录，保留AI1及其他任务的文件。旧baseline、正式代码和官方输入未变。

共读取并检查657条记录：647条完整“策略×案例”结果、7条计算到限结果、3条主动停止快照。它们分布在12个比较批次及未完成清单中，**不是657个独立场景**；压力集、部分前序案例与参照存在复用。另独立复算30,694条动作的路程、操作费和累计时间。源数/布局/误差分组按样本数加权后回到对应总体均值。

原始实验的反馈与几何核验保留原报告边界；本次未重新运行所有几何检查。全部成绩为自建仿真，未启动官方正式测试。源数与分布等存在混杂，分组均值不等于因果结论。所有AI整理和核验仍待团队人工审阅。

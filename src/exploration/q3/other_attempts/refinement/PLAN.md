# 后续测点与清除动作的增量改进

授权：用户要求开始优化，报告具体改动、改善和恶化。只使用自建环境，不运行正式测试。

固定对照为当前自适应第二站算法；保留 scan7_r60 的背景结果。所有版本共用由第一站公开反馈选出的同一个第二站，避免初始选择变化混入后续收益。

三个增量：F1 过滤可证明冗余的无信号检测；F2 在 F1 上比较原测点、横向对称测点及扫描未知频道选项；F3 再加入覆盖当前保守区域的两次/三次清除方案。候选用相同条件场景、相同 F1 后续规则，完整模拟至全清，按平均剩余秒数选择。不使用旧 W/G 评分或人为边界惩罚。

工作概率假设为任务圆内均匀位置、源数10—16均匀、频道子集均匀、接收半径1000—1500均匀、方向误差有界均匀近似。由全部公开历史约束条件采样；用有限粒子近似积分，采样耗尽只回退旧动作，不证明源不存在。同位置历史反馈固定，未来使用固定哈希误差场。

先在演示案例加4个既有诊断案例上检查三个增量。冻结后用24个新种子（310100起，四种空间布局、三种误差各两例）确认，并检查8个既有压力案例。若明确修改，旧确认集转诊断，另用新种子确认。案例不按结果筛选，失败保留；同案配对汇报总时、每源、移动、检测切频、失败清除、胜负和最坏退步。硬上限为3000动作、180虚拟分钟、每局1200墙钟秒。

验证包括历史冗余证明、清除覆盖几何、条件样本与历史一致、原地误差固定、不读取实际真值、逐动作独立重算及全清。若更复杂版本无稳健收益，推荐较简单版本，不为保留功能继续加权调参。

用户后续要求：上述比较完成后，再独立抽取一个随机场景，逐动作审查不合理行为；发现具体问题则微调，再以新种子验证。该随机场景作为诊断，不加入原确认集；微调前后成绩分开，新验证使用320100起的新种子。

## 阅读顺序

先查[src总入口](../README.md)及当前主体，再按问题进入旧分支。历史文档里的“当前”“下一步”“授权”“停止”等属于形成当时的记录，不恢复历史自动化或保护规则。

各分支的原代码、运行记录、失败和停止证据均保留。原批次输出位置不动，[结果导航](../../outputs/exploration/README.md)与[src/migration_manifest.json](../migration_manifest.json)提供追溯。

旧目录层级敏感的脚本不全部改写。Q3当前主体使用清单运行器；Q4主体使用src/q4独立入口。历史精确复现应选取对应批次source快照，不用新源码冒充旧算法。

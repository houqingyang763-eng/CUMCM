# src 三类组织规则

本目录按用户于2026-09-13的明确安排分为三类：

- `exploration/` 是之前探索的方法与实验归档，属于根目录正式代码规则的历史例外；归档不表示采纳，旧指令不自动生效。
- `q3/` 是第三问F3及F3改的主体与对照入口；`q4/` 是第四问shared25主体。
- 新实验结果仍写入仓库 `outputs/`。原始输入只读，沿用根目录的正式测试逐次授权要求。
- 冻结源码和证据保留原字节，避免破坏SHA256。禁止把缓存、私有会话和Windows目录联接提交Git。
- 阅读总入口 `README.md`，跨机器运行先查 `GITHUB_DELIVERY.md`。现有 `experiments/` 实体目录不得为创建兼容联接而删除或覆盖。
